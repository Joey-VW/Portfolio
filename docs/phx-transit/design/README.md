# PHX Transit Pulse design references

## Dashboard concept

`dashboard-concept-1.png` is the primary visual reference for:

- overall dashboard structure;
- map dominance;
- information density;
- panel hierarchy;
- compact KPI presentation;
- alerts and route-status positioning;
- dark operations-center styling.

Treat it as a visual and structural north star, not a literal functional
specification.

The implementation may adapt individual controls, navigation elements, labels,
and metrics to match the verified data contract, accessibility requirements,
responsive behavior, and explicit synthetic-data disclosures.

Operational values shown in the concept are illustrative and do not establish
accepted PHX Transit Pulse metrics or provider-performance claims.
