# Quote-to-Cash Workflow Audit

This project rebuilds a legacy notebook as a deterministic, fictional audit of three related systems:

1. CRM opportunities
2. Billing subscriptions
3. Revenue-recognition records

The public story asks: **where is revenue getting stuck between a sale and recognized revenue?**

## Reproduce the artifact

```bash
python tools/qtc/build_case_data.py
python tools/qtc/validate_case_data.py
```

`build_case_data.py` calls the fixed-seed generator, audits the joins and timelines, calculates stage-specific cohorts, and writes `data/quote-to-cash-workflow-audit.json`.

To inspect the generated source entities as CSV:

```bash
python tools/qtc/generate_mock_data.py --output-dir data/qtc-source
```

The CSVs are optional generated fixtures and are not required by the browser.

## What changed from the legacy notebook

- The source is generated by documented rules with seed `20250630`.
- Opportunity, subscription, and revenue data remain separate entities.
- Missing downstream records remain visible as audit findings.
- Each conversion and timing metric has its own eligible cohort.
- Median, average, p75, and p90 replace a mean-only timing story.
- Broken joins, duplicate identifiers, impossible sequences, stalled states, and unusually slow transitions are detected.
- A browser scenario shows how reducing activation delay changes the median total lifecycle.

All organizations, records, amounts, statuses, dates, and outcomes are fictional. The generator is designed to demonstrate analytical method, not benchmark a real company's performance.
