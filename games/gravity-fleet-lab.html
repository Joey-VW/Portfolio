Gravity Fleet Lab

Command an orbital fleet, then turn each match into a clear tactical story.

Command ships between planets, build short-range wormholes, outmaneuver a simple AI opponent, and watch launch spikes and fleet pressure live, then review the telemetry generated by each match.

PlayView analytics
Mission briefing⌄
  1. Start with your cyan home planet.
  2. Hold near an owned planet to gather ships.
  3. Drag and release to launch fleets toward Neutral, Red, Orange, or star objectives.
  4. Planets drift on slow orbital paths; time launches and wormholes around the moving system.
  5. Right-click, drag, and release to create a one-way cyan wormhole; right-click an entrance to collapse it.
  6. Capture every Red and Orange planet or eliminate all AI-controlled ownership, then inspect the live and post-match analytics dashboard.
