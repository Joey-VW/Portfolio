Case study

Video Cutter Lite

A lightweight desktop workflow for marking removal ranges and automating repeat video cuts.

Back to projectsDiscuss this work

Problem

Small editing tasks can become slow when users need to remove many repeated sections and verify every cut manually.

Solution

Prototyped a focused utility around timeline selection, preview controls, crop overlays, and FFmpeg-powered export steps.

Tech stack

PythonDesktop UIFFmpegMedia automationUX prototyping

Key features

  • Removal range markers
  • Playback and preview controls
  • Crop overlay concepts
  • Export automation path

Architecture / data flow

The UI captures user-defined edit ranges, passes a cut plan to media tooling, and exports a cleaned video with fewer manual editing steps.

Impact

Reduces friction for repetitive media cleanup and demonstrates product thinking outside pure analytics.

What I’d improve next

Harden long-file performance, add undo/redo, and package the app for non-technical installation.
