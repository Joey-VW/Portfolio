Behind the demo

About Postcard Atlas

Postcard Atlas is a fictional travel publication built to demonstrate a real content system without exposing client material. Its familiar journal format gives the publishing workflow a clear, approachable front end.

How it works

A simple publishing path

Structured rows become journal entries, grouped photos, and map stops through shared browser-side normalization. A nontechnical publisher can update content without editing HTML or JavaScript.

The current portfolio fixture is local and fictional. The production pattern supports published Google Sheets CSV data, public Drive media, and an optional Google Form submission path.

Background videos, loading states, filters, deep links, map interactions, and failure fallbacks remain part of the demonstration.
